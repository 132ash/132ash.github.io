SIGOPS ATC ’262026

Efficient Strict Serializability for Stateful Serverless Workflows via Workflow Reconciliation

Shenghao Ao, Zijun Li, Chuhao Xu, Quan Chen, Shuo Quan, Yanan Yang, Meiqi Zhu, Yujun Wang, Jie Wu, and Minyi Guo

The 2026 ACM SIGOPS Annual Technical Conference

FaaSRep learns dependencies from an optimistic execution to guide an organized retry, providing strict serializability for stateful serverless workflows while reducing redundant computation and scheduling.

1.44–2.73×average throughput vs. Concord on the evaluated real-world applications.

PDF↗ DOI↗ BibTeX↗
Read abstract

Serverless computing is increasingly used for complex applications built from stateful workflows, but efficient support for strict serializability remains challenging. FaaSRep addresses repeated conflict-and-retry cycles with workflow reconciliation: it learns function-level dependencies during validation and uses them to guide an organized retry. A hybrid optimistic/pessimistic protocol handles application-level aborts. Function-level re-execution and a peer-to-peer fast path reduce redundant work and control-plane overhead. On the evaluated real-world applications, FaaSRep improves average throughput by 1.44–2.73× over Concord and 3.81–9.01× over Beldi.
